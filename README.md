# Dockerized WordPress Flooring Ecommerce Store

A WordPress + WooCommerce ecommerce project built using Docker Compose.

## Technologies Used
- Docker
- Docker Compose
- WordPress
- MySQL
- WooCommerce
- Elementor

## Features
- Ecommerce product catalog
- Responsive Elementor pages
- WooCommerce storefront
- Product categories
- Dockerized local environment

## Local Setup
Run:

docker compose up -d

Then open:
http://localhost:8080
